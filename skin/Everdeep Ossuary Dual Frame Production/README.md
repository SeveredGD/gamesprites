# Ossuary Dual Frame — Ornate Silver

Production preparation of the selected concept #4 for Everdeep's Equipment + Vault stage.

## Use these files

- `ossuary-dual-frame-master-1284x540.png` — fixed-size drop-in master matching the current stage.
- `ossuary-dual-frame-master-1935x813.png` — full-resolution transparent master.
- `slices/` — eleven production pieces: eight outer-frame pieces plus a separately three-sliced center divider.
- `slice-manifest.json` — content-well rectangles and assembly rules.
- `ossuary-dual-frame-alpha-preview.jpg` — dark-background alpha check.
- `ossuary-dual-frame-slice-guide.png` — visual map of every exported region.

The separately sliced divider is deliberate. A conventional single nine-slice would stretch or compress its skulls, finials, and chains. The outer frame behaves like an eight-piece nine-slice perimeter, while the divider uses fixed top/bottom caps and one vertically stretchable middle rail.

The recolored metal follows the existing ornate-silver book reference: cool desaturated silver highlights, charcoal-black recesses, and only restrained warm grime in crevices.
