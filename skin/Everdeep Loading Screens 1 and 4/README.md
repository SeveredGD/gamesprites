# Everdeep loading screens #1 and #4

Working standalone prototypes for:

- #1 The Descent Gate
- #4 The Sealed Reliquary

Open `index.html` and switch between the screens with the preview controls. The slider drives both loaders dynamically. Add `?clean=1` to the URL to hide prototype controls.

All generated text and fake loading values were removed from the background plates. Titles and labels use the locally bundled Grenze font. The gate uses the production Frost Reliquary layered bar; the reliquary uses a live SVG semicircular progress stroke.

No current game or production HTML file was modified.
