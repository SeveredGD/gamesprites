EVERDEEP CHARACTER SELECT LAYOUT MOCKUPS

Open index.html.

Use the top controls to compare three layouts and switch between desktop and phone:

1. Hero Focus
   Recommended starting point. Class choice is compact, the selected class uses the same silhouette treatment as the equipment paper doll, and character saves are the primary interaction.

2. Class Gallery
   Strongest first-launch presentation. It makes the four classes feel important, then keeps the last-played character in a compact drawer.

3. Roster Ledger
   Most efficient for returning players with many saves. It scales cleanly and keeps character-management actions out of the main Play path.

The page uses local copies of the current Everdeep class icon sheet and normalized ornate-silver skin assets. It does not modify the game copy.

Suggested production direction:
- Use Hero Focus for the normal returning-player screen.
- Use Class Gallery only for a player's first character, then transition to Hero Focus.
- Keep Delete behind a separate Manage action or confirmation overlay.
- Keep cloud status in the footer; only expand it when sync needs attention.
