# Everdeep new backgrounds

This folder contains production copies only. Generation sources are intentionally excluded.

## Layout

- `acts/`: five approved act backgrounds.
- `delves/`: two pixel-art delve backgrounds.
- `Preview_All_Backgrounds.html`: plays all seven ambient loops together.
- `BACKGROUND_GENERATION_NOTES.md`: composition and animation rules used for this set.

## Files for each background

- `.png`: lossless static background.
- `.webp`: compact static background.
- `-loop-preview.webp`: directly playable six-second preview.
- `-animated-atlas.webp`: game-ready 9×8 atlas containing 72 frames.
- `-animated-atlas.json`: frame dimensions and 12 FPS looping metadata.

Act animation frames are 455×256. Delve animation frames are 512×256. The original game assets were not overwritten.
